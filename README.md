# Concurso AI

Primeira versão do front-end para a preparação de Escrevente Técnico Judiciário do TJSP. A interface segue o [guia de estilos](docs/guia-de-estilos.md).

## Rodar localmente

Execute o comando abaixo na raiz do projeto.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Acesse [http://127.0.0.1:8000](http://127.0.0.1:8000). O front usa HTML, CSS e JavaScript, sem etapa de instalação ou build.

A trilha, a seleção de materiais e os testes usam dados de exemplo em `frontend/data.js`. O resumo e as provas anteriores apontam para as fontes oficiais. A disponibilidade, o cronograma e o progresso ficam no armazenamento local do navegador.
